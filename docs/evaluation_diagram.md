# Диаграмма последовательности оценки качества RAG-пайплайна

## Диаграмма последовательности в формате Mermaid

```mermaid
sequenceDiagram
    participant Пользователь
    participant Скрипт оценки (evaluate.py)
    participant RAG-бот (rag_bot.py)
    participant FAISS индекс
    participant LLM модель
    participant Логирование

    Пользователь->>Скрипт оценки: Запуск оценки
    Скрипт оценки->>Скрипт оценки: Загрузка golden_questions.txt
    
    loop Для каждого вопроса
        Скрипт оценки->>RAG-бот: Отправка тестового вопроса
        RAG-бот->>FAISS индекс: Поиск релевантных чанков
        FAISS индекс-->>RAG-бот: Возврат найденных чанков
        
        alt Найдены релевантные чанки
            RAG-бот->>LLM модель: Формирование промпта с контекстом
            LLM модель-->>RAG-бот: Генерация ответа
        else Чанки не найдены
            RAG-бот->>RAG-бот: Формирование ответа "Не знаю"
        end
        
        RAG-бот-->>Скрипт оценки: Возврат ответа
        Скрипт оценки->>Скрипт оценки: Оценка корректности
        Скрипт оценки->>Логирование: Сохранение в evaluation_logs.jsonl
    end
    
    Скрипт оценки->>Скрипт оценки: Анализ результатов
    Скрипт оценки-->>Пользователь: Отчёт об оценке
```

## Диаграмма сценариев ошибок

```mermaid
sequenceDiagram
    participant Тест
    participant evaluate.py
    participant rag_bot.py
    participant FAISS
    participant LLM

    Тест->>evaluate.py: Запуск тестирования
    
    par Успешный сценарий
        evaluate.py->>rag_bot.py: Вопрос с известным ответом
        rag_bot.py->>FAISS: Поиск чанков
        FAISS-->>rag_bot.py: Найдены чанки
        rag_bot.py->>LLM: Генерация ответа
        LLM-->>rag_bot.py: Корректный ответ
        rag_bot.py-->>evaluate.py: Ответ с источниками
    and Сценарий "не знаю"
        evaluate.py->>rag_bot.py: Вопрос без ответа в базе
        rag_bot.py->>FAISS: Поиск чанков
        FAISS-->>rag_bot.py: Чанки не найдены
        rag_bot.py-->>evaluate.py: Ответ "Не знаю"
    and Сценарий ошибки индекса
        evaluate.py->>rag_bot.py: Любой вопрос
        rag_bot.py->>FAISS: Поиск чанков
        FAISS-->>rag_bot.py: ОШИБКА: Индекс повреждён
        rag_bot.py-->>evaluate.py: Ошибка поиска
    and Сценарий ошибки LLM
        evaluate.py->>rag_bot.py: Вопрос с известным ответом
        rag_bot.py->>FAISS: Поиск чанков
        FAISS-->>rag_bot.py: Найдены чанки
        rag_bot.py->>LLM: Генерация ответа
        LLM-->>rag_bot.py: ОШИБКА: Таймаут API
        rag_bot.py-->>evaluate.py: Ошибка генерации
    end
    
    evaluate.py-->>Тест: Сводный отчёт с ошибками
```

## Ключевые компоненты

1. **Скрипт оценки**: `evaluate.py` (автоматическое тестирование)
2. **Золотой набор**: `golden_questions.txt` (19 вопросов)
3. **RAG-бот**: `rag_bot.py` (обработка запросов)
4. **FAISS индекс**: поиск релевантных чанков
5. **LLM модель**: генерация ответов
6. **Логирование**: `evaluation_logs.jsonl` (результаты тестирования)

Диаграмма показывает процесс оценки качества, включая нормальные сценарии и обработку ошибок (пустой индекс, невалидный чанк, ошибки генерации).
